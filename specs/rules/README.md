# Rules

These rules apply to all specs in `specs/active/` unless a spec explicitly documents an exception.

## Rule Set

- `php.md`: PHP implementation rules.
- `testing.md`: testing expectations.
- `naming.md`: naming and file organization rules.
- `spec-writing.md`: how specs should be written and maintained.

## Usage

Reference the relevant rules while refining a spec, and document any justified exception inside the spec itself.
