# Script Examples

Ejemplo autocontenido con datos dummy.

Incluye:
- `.escripta/configs` con configuracion local de ejemplo
- `config.php` para poblar `config.gen` y `escripta_env.sh`
- `generate.php` para sincronizar en carpetas `p_*` ejemplos ya materializados

Regenerar configuracion:

```bash
php config.php
```

Regenerar scripts:

```bash
php generate.php
```
