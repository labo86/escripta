# Release installs agent guide into target repositories

Created At: 2026-04-24 19:03:40
Last Updated At: 2026-04-24 19:41:00
Template Version: v1

## Context
`ESCRIPTA_AGENTS.md` existe en este repositorio como guía corta para agentes, pero un repositorio target que instala o actualiza Escripta no recibe todavía esa guía ni un hint claro para integrarla en su propio `AGENTS.md`.

La idea es que el release de Escripta pueda distribuir una guía agent-optimized y facilitar que otros repositorios la hagan visible para agentes sin copiar contenido manualmente.

## Objective
Agregar al flujo de release/instalación una funcionalidad para instalar `ESCRIPTA_AGENTS.md` en un repositorio target y generar un hint que un agente pueda leer para integrarlo en `AGENTS.md`.

## Scope
- Decidir si `ESCRIPTA_AGENTS.md` se empaqueta como asset de release, dentro del PHAR, o ambas opciones.
- Definir comando o modo de instalación en el target para escribir la guía en una ubicación estable.
- Definir ubicación recomendada en repos target, por ejemplo:
  - `.escripta/ESCRIPTA_AGENTS.md`.
- Generar un hint legible para agentes con una instrucción tipo:
  - "Read `.escripta/ESCRIPTA_AGENTS.md` when touching Escripta config, generated env vars, or scripts that consume `ESCRIPTA_*`."
- Evitar sobrescribir cambios locales sin confirmación o sin modo explícito.
- Agregar/actualizar tests.
- Incluir el número de versión de Escripta en los archivos generados por el instalador de guía y en el asset de guía generado para release.

## Out of Scope
- Modificar automáticamente `AGENTS.md` en repos target sin una política clara de seguridad/idempotencia.
- Diseñar un instalador general para todas las docs de Escripta.
- Cambiar el contrato de `fetchConfig`.

## Success Criteria
- Un release de Escripta incluye o puede exponer la guía para agentes.
- Un repo target puede instalar/actualizar la guía mediante un flujo documentado y repetible.
- El flujo produce un hint estable para que un agente/persona lo agregue a `AGENTS.md`.
- El proceso es idempotente y no pisa contenido local inesperadamente.
- Tests cubren instalación inicial y actualización con archivo preexistente.

Entregado y validado. El PHAR incluye la guía como recurso, expone `--install-agent-guide` con `--force` opcional, instala `.escripta/ESCRIPTA_AGENTS.md`, genera `.escripta/AGENTS_HINT.md`, y el release publica `ESCRIPTA_AGENTS.md` como asset adicional.
